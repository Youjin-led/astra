# ASTRA — инструкция по исходным изображениям

Эта версия создана заново по композиции и надписям на присланном референсе. Предыдущая модель Blender и размеры версии V2 не использованы.

## Файлы

- `assembly_from_reference_ru.pdf` — 24 страницы: исходные размеры, схема расположения, слои, перечень деталей, формулы коробов, узлы акрила / LED и 11 шагов сборки.
- `reference_dimensions.csv` — все шесть строк исходной таблицы размеров, открывается в Excel (UTF-8, разделитель `;`).
- `reference_dimensions.json` — сведения с изображения; неизвестные координаты оставлены пустыми.
- `reference_facade_preview.png` — предварительный просмотр страницы PDF с исходным фасадом.
- `measurements_template.csv` — бланк замеров экспонатов для мастера.
- `create_reference_manual.py` — генератор PDF; использует Python и ReportLab, без Blender.

Сохранены основной габарит 1200 × 800 мм и нижняя ниша 1160 × 200 × 70 мм. Стенки коробов 15–18 мм и слой дерева 30–40 мм оставлены как варианты исходного референса, а не произвольно выбранные толщины.

## Что ещё нужно для мастерской

Референс не содержит координат всех проёмов, отдельных размеров малых боковых ячеек, однозначного положения правой средней ниши, точного разреза, параметров магнитов, крепежа и рельефа. Поэтому это инструкция и размерное техническое задание, **не окончательная карта раскроя или готовая программа ЧПУ**. Уточнения перечислены на последней странице.

При отдельном накладном слое дерева указанная глубина 70–100 мм противоречит пакету материалов. Необходимо согласовать разрез до изготовления. Нагрузка крепления из референса не подтверждена.

## Исходные фотографии

Оригинальное изображение получено из ZIP пользователя и сохранено в `source/08387e1d-4358-4564-9a3d-56a1dc0bfdc0.png`. На обложку и страницу результата помещён фасад; в разделы сборки — соответствующие фрагменты коробов, декора, LED, магнитного узла и крепления на стену. На последней странице исходный лист показан целиком.

Изображение встроено в PDF как один оригинал; отдельные фрагменты показаны через области обрезки при вёрстке. Генеративная перерисовка и прежние Blender-рендеры не используются. Дополнительные схемы формул коробов, материалов и соединений оставлены плоскими пояснениями.

Исходный лист содержит визуализацию проекта, а не подтверждение изготовленного изделия. Пиксельные пропорции не используются как точные производственные размеры.

## Повторное создание

```sh
python /workspace/astra/reference_project/create_reference_manual.py
```

Шрифты DejaVu встраиваются в PDF, инструкция читается на Windows без установки шрифтов.
