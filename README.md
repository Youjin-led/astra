В `project_v2` находятся спецификация 29 деталей, размерная разметка SVG/DXF, профили заготовок, раскрой и 11 этапов сборки. [Описание и ограничения версии](project_v2/README.md).

Это документация корпуса для прототипа. Перед окончательным раскроем нужны размеры экспонатов, подбор реальной фурнитуры и проверка крепления по стене и весу. Портрет, орнамент и надписи остаются эскизными; готовые траектории ЧПУ не включены. Нижний проём в V2 уменьшен до 1110 × 200 мм ради доступа к съёмной панели при общей ширине 1200 мм.

`design` содержит первую эскизную версию и материалы, используемые при воспроизведении V2.
