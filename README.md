# ASTRA — витрина / инструкция по исходному референсу

Актуальная версия — инструкция с оригинальным изображением и его фрагментами из присланного ZIP:

- [Новый комплект — ZIP](https://github.com/Youjin-led/astra/raw/refs/heads/main/astra_reference_package.zip)
- [Новая инструкция — PDF, 24 страницы](https://github.com/Youjin-led/astra/raw/refs/heads/main/reference_project/assembly_from_reference_ru.pdf)
- [Описание и нерешённые размеры](reference_project/README.md)

Исходные размеры сохранены, включая нижнюю нишу 1160 × 200 мм. Для окончательного изготовления нужны уточнения, перечисленные в инструкции. Оригинальное изображение получено из ZIP и встроено: фасад, слои, детали и фрагменты для сборки.

В `project_v2` находятся спецификация 29 деталей, размерная разметка SVG/DXF, профили заготовок, раскрой и 11 этапов сборки. [Описание и ограничения версии](project_v2/README.md).

Это документация корпуса для прототипа. Перед окончательным раскроем нужны размеры экспонатов, подбор реальной фурнитуры и проверка крепления по стене и весу. Портрет, орнамент и надписи остаются эскизными; готовые траектории ЧПУ не включены. Нижний проём в V2 уменьшен до 1110 × 200 мм ради доступа к съёмной панели при общей ширине 1200 мм.

`design` содержит первую эскизную версию и материалы, используемые при воспроизведении V2.
